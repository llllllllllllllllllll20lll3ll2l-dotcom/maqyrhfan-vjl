# Вторжение (Vtorzheniye)

Хоррор-мод на **Fabric** для **Minecraft 26.3**. Не добавляет измерений и не меняет генерацию мира —
он просто делает обычный мир *неправильным*.

> Ты живёшь в своём доме. Ставишь факелы. Спишь по ночам.
> А потом замечаешь, что факелы гаснут сами, стены стали мягкими,
> и в углу кто-то стоит. Он не двигается, пока ты смотришь.

## Что внутри

**Гость** (`entity.vtorzheniye.guest`) — центральное существо.
2,6 блока ростом, слишком худой, без лица. Не бегает и не рычит: идёт ровным шагом.
Пока игрок смотрит на него, Гость **замирает** — он не любит, когда его видят.
Отвернулся — он снова идёт. От ударов не отступает, огня и падений не боится.

**Гниль** — невидимый счётчик 0…100 на каждого игрока:

| Источник | Эффект |
|---|---|
| Свет 12+ | гниль не растёт |
| Темнота | +3 за тик начисления |
| Под землёй (Y < 45) | +1 |
| Ночь | +1 |
| Сон | −3 (сон отматывает гниль, но спать опасно — см. ниже) |

**Порча мира** (`WorldRot`), по мере роста гнили:
- 25+ — рядом гаснут факелы, фонари и костры (фонари на цепях заменяются цепью);
- 45+ — на поверхностях прорастает скулк-жила;
- 60+ — если ты заснул, сон прерывается: Гость уже стоит у кровати;
- 100 — Гость начинает приходить сам, вне поля зрения.

**Тихие события** (раз в ~3 минуты, шанс пропорционален гнили):
стук в дверь, шёпот за затылком, стук сердца и тошнота, скрежет по стене, низкий гул.

**Мясной оверлей** (`FleshOverlay`) — клиентский HUD: края экрана затягивает тёмно-красным,
пульсация в такт сердцу. Сила берётся из пакета `FleshPulsePayload`.

## Сборка

Нужны **JDK 25** и интернет для первой загрузки зависимостей.

```bash
./gradlew build        # готовый мод: build/libs/vtorzheniye-1.0.0.jar
./gradlew runClient    # тестовый запуск клиента
```

Версии (см. `gradle.properties`):
`minecraft 26.3` · `fabric-loader 0.20.1` · `fabric-api 0.166.2+26.3` · Java 25 · Loom 1.19-SNAPSHOT.

## Зависимости

- **Fabric Loader** ≥ 0.20.1
- **Fabric API** (обязательно)
- Java 25

GeckoLib **не требуется**: модель Гостя собирается кодом (`GuestModel.createBodyLayer()`).

## Ассеты

Все ассеты сгенерированы процедурно и лежат в репозитории:

- `textures/entity/guest.png` — 64×64, каноническая раскладка скина: глазницы-провалы,
  щель рта с зубами, рёбра под кожей, прожилки и гниль;
- `icon.png` — иконка мода;
- 21 файл `sounds/*.ogg` — 9 уникальных звуков по 2–3 варианта
  (стук, шёпот, дыхание, скрежет, сердце, крик, ритуальный стук, гул, выломанная дверь).

## Настройка сложности

В игре есть правило мира:

```
/gamerule vtorzheniye:intensity 0   # мод молчит полностью
/gamerule vtorzheniye:intensity 1   # по умолчанию: тихо и медленно
/gamerule vtorzheniye:intensity 2   # гниль вдвое быстрее, события вдвое чаще
```

Остальные числа — `FleshNetwork.MAX`, `ACCRUE_EVERY`, `MINUTES_BETWEEN_EVENTS`
и `WorldRot.ROT_INTERVAL` — вынесены в константы в начале классов.

## Лицензия

CC0-1.0 — делайте что хотите.

## Чего здесь намеренно нет

- **Нового измерения.** Хоррор работает только там, где ты думал, что в безопасности.
- **Крови и расчленёнки в кадре.** Страх строится на силуэтах, звуке и ожидании.
- **Скримеров на каждому шагу.** Один крик за всю ночь страшнее десяти.
- **GeckoLib.** Модель собирается кодом — меньше зависимостей, проще сборка.
