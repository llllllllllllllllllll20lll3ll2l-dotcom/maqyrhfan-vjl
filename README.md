# Бесконечная аркада

Три браузерные мини-игры без уровней и фиксированного финала. Рекорды сохраняются в браузере. Управление: клавиатура, экранные кнопки и жесты в поддерживаемых играх.

## Локальный запуск

Откройте `index.html` или запустите `python3 -m http.server 8000` из корня проекта.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**. Затем запустите **Deploy arcade to GitHub Pages** из рабочей ветки в разделе **Actions**. Если окружение `github-pages` ограничено основной веткой, добавьте рабочую ветку в список разрешённых веток окружения. Ссылка на сайт появится в результате деплоя.
